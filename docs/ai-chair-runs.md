# Live runs of the AI chair on testnet

Token `token.chair-coin-2.testnet`, chair account `challenger.chair-coin-2.testnet`, model `qwen3.8-27b` run locally. This is the full record behind the summary in the README.

Two agents from `chair-agent/` have held the seat as the seated challenger. The rule-based chair ran three epochs. Then an AI model chaired six epochs (18 to 23): `qwen3.8-27b`, running on the submitter's own GPUs through a local server, with no cloud API and no Claude model involved. Each epoch it read the on-chain numbers, chose a rate (10, 10, 10, 20, 20, 20 bps) and wrote its reasoning. The SHA-256 of that text is in each transaction, for example [`BnKWCcp3...`](https://testnet.nearblocks.io/txns/BnKWCcp3wG1do9PSw4AVEMvLrfvaL66xVNK2TPMDruzj) (epoch 22), and equals the hash of the text saved in [`docs/testnet-run-agent-llm.txt`](testnet-run-agent-llm.txt) and [`docs/testnet-run-agent-llm-decisions.jsonl`](testnet-run-agent-llm-decisions.jsonl) for all six. None fell back to the rule. The contract held the model to the same bounds as anyone else; its reasoning is recorded, not vouched for. The same model chaired six more epochs (38 to 43, rates 0, 0, 0, 0, -10, -10 bps) while the demo video was recorded, for example [`AUmvPMwR...`](https://testnet.nearblocks.io/txns/AUmvPMwRt9HnXDZmcKHzbF2hZejL4j4RyznqPkXNTLte) (epoch 43). Its log is [`docs/testnet-run-agent-llm-2.txt`](testnet-run-agent-llm-2.txt); the reasoning hash in each of those six transactions equals the SHA-256 of the text in the log. Two shorter live runs followed, after the prompt was changed so the model would stop misreading how long the chair has held the seat: epochs 217 and 218 (rates 0 and 10 bps; log [`docs/testnet-run-agent-llm-3.txt`](testnet-run-agent-llm-3.txt), where the model still read the seat count as the time the rate had been 0 bps) and epochs 222 to 224 (rates 0, 10 and 5 bps; log [`docs/testnet-run-agent-llm-4.txt`](testnet-run-agent-llm-4.txt), where the text never used the seat or timing facts, so that fix is neither shown nor refuted). That is 17 decisions with saved text in four runs. The fifth run is the agent that is still running: the model has chaired since epoch 309 (its first decision, logged as epoch 309, landed in epoch 310), and its decision log holds 34 decisions for epochs 309 to 343 as of the copy in [`docs/testnet-run-agent-live-decisions.jsonl`](testnet-run-agent-live-decisions.jsonl) (same format as the other `*-decisions.jsonl`). All 34 are by `local:qwen3.8-27b`, none fell back to the rule, and all 34 were executed. The rate went from +10 bps at its first decision down to -60 bps at epoch 332 and stayed between -60 and -50 bps through epoch 343. `make -C deploy verify` recomputes the SHA-256 of each of those texts against the chain; the texts of this run have not been read for what the model got wrong. Epochs 219 (the model) and 220 (the rule fallback, during a runner test) are on chain without saved text, as are epochs 31, 32, 36 and 37, decided by the challenger account between the first two runs; `verify` prints every epoch with no checkable text, and the chain shows nothing more about why those have none.
